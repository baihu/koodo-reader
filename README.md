

## 在原版基础之上做了如下修改
- S3、webdav协议目前不需要Pro就能使用，只限于桌面端，打了zip压缩包。
- 桌面端现已支持只接受 Zotero 风格请求的 WebDAV 服务，我用的中国科技云的网盘https://data.cstcloud.cn/，实名认证20G。
- 在 `设置 -> 同步与备份 -> WebDAV` 中，将 `Client type` 填为 `zotero`；`https://data.cstcloud.cn/dav` 会被自动识别为兼容模式。
- 该兼容模式可用于桌面端的同步、备份，以及云端书库浏览和导入。
- 新增了侧边栏“云书库”入口，位置在“我的书架”上方，可直接浏览云端文件并导入支持的书籍格式。
